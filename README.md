---

## 🎯 Objetivo
Transformação e saúde através da disciplina, alquimia alimentar e monitoramento tecnológico. 
- **Meta:** Perda de peso sustentável sem cirurgia nem remédios caros.
- **Acompanhamento:** Controle exato de déficit calórico e documentação visual do progresso.

---

## ⚙️ Funcionalidades do Repositório

* **Calculadora Metabólica Interativa (`calculadora_dia.py`):** Script em Python ajustado para as métricas corporais exatas (TMB + cálculo de gasto por passos da palmilha).
* **Guias de Alquimia Alimentar:** Módulos de otimização de saciedade e termogênese (`HAK01_ABACAXI`, `HAK02_METABOLISMO`, `SUCO_OPTIMIZER`, `SOBREMESA_MOUSE`).

---

## 💻 Como Executar a Calculadora (Pydroid 3 / Terminal)

1. Abra o arquivo `calculadora_dia.py`.
2. Execute o código no botão **Play (▶)**.
3. Insira o total de passos e as calorias consumidas no dia para receber o diagnóstico instantâneo.
